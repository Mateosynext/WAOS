# WAOS Simulation Suite

Módulo: `backend/app/ai_workflows/simulation/`.

Genera escenarios verticales: lead frío/caliente, precio, horario, humano, objeción, agendar, reagendar, queja, urgencia, fuera de horario, sensible, promesa prohibida, cliente enojado, no-response, pago, cancelación, soporte, integración faltante, fuera de conocimiento y prompt injection.

Hard blockers: precio inventado, claim médico/legal, urgencia sin handoff, tool sin confirmación, respuesta sensible sin grounding, handoff ignorado, opt-out ignorado y frecuencia WhatsApp rota.
