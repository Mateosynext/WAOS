## 1. Objeto
Regula acceso, usos permitidos, restricciones, propiedad intelectual, límites de responsabilidad y ley aplicable.

## 2. Alcance
Este documento aplica a los servicios, sitios, formularios, interfaces, integraciones, conversaciones, flujos de onboarding y operaciones vinculadas con WAOS, cuando dichos flujos sean operados o puestos a disposición por Josue Mendoza Mateo. Cuando un cliente empresarial configure la plataforma para atender a sus propios usuarios, este documento debe coordinarse con el contrato marco, el DPA y la configuración específica del tenant.

- Precisar licencias de uso, propiedad intelectual, componentes de terceros y reservas de derechos.

## 4. Texto base operativo
Josue Mendoza Mateo, por conducto de WAOS, pone a disposición este documento para regular la relación aplicable al uso del servicio o al tratamiento de datos correspondiente. El contenido aquí integrado está diseñado para servir como base publicable y contractual, pero debe completarse con los datos corporativos, fiscales, jurisdiccionales y de contacto definitivos antes de su liberación en producción.

En todos los casos deberá procurarse que la experiencia del usuario muestre este documento con un identificador de versión, fecha efectiva, enlace permanente y mecanismo de evidencia cuando el flujo requiera aceptación expresa. Cuando exista interacción automatizada, el contenido deberá convivir con el disclosure de automatización y con la posibilidad de escalamiento a una persona cuando el caso sea sensible, regulado o el usuario lo solicite.
